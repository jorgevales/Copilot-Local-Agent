# FNZ — Scripts and projects

This repository contains the source projects from the local `Scripts and projects` folder.

## Projects

- [CDD Audit / Documents review workflow](CDD%20Audit/Documents%20review%20workflow/README.md): portable document-review preparation, processing and workflow tools.
- [CDD Audit / Operations Pool keep-awake utility](CDD%20Audit/OperationsPool-KeepAwake/README.md): Windows support utility with its documented operational limits.
- [Copilot Local Agent](Copilot%20Local%20Agent/README.md): Microsoft 365 Copilot UI orchestrator, controlled local tools, user attachments and per-user OneDrive delivery.

Use each project's own setup instructions, launchers and test guidance. Dependencies and deployment requirements differ between projects.

Only project source, documentation, schemas, guidance and intentional test fixtures are published. Personal settings, generated documents, logs, browser profiles, virtual environments and runtime evidence stay local. CDD test fixtures are explicitly sanitized or simulated; see their accompanying README.

The earlier Copilot-only release remains in Git history. Current releases organize the projects into their named folders without changing their source behavior.
